# Privacy policy: cloud-architect plugin

Last updated: 10 November 2026

The cloud-architect plugin for Claude collects no data.

- **No collection or telemetry.** The plugin has no servers, analytics or
  tracking, and sends nothing to its author or anyone else.
- **No code, network access or credentials.** The plugin is instructions and
  reference data only: it contains no scripts or programs, bundles no MCP
  servers or hooks, makes no network calls, and never reads credentials,
  environment variables or `.env` files.
- **What it reads.** Only on your machine and only through Claude Code's own
  tools: your answers, `.cloud-architect/org.yaml` if you create one, and
  files in the repository you're working in (to find the tools your team
  uses and how existing code is built).
- **What it writes.** Markdown design documents, only under
  `docs/architecture/` in your repository and only where you agree.

Your conversation with Claude, including what the plugin's instructions bring
into it, is handled by Anthropic under the terms and privacy policy of the
Claude product you use. The plugin doesn't change that.
